## 💡 Pro Tips

### Tip 1: Use GitHub Copilot for Commits
- Generates professional-sounding messages
- Saves time thinking about what to say
- Consistent formatting across commits

### Tip 2: Small, Logical Commits
- Don't commit everything at once
- Split into 3-5 logical groups:
  - Documentation
  - Code
  - Supporting files
- Easier to track changes

### Tip 3: Good Commit Messages
- Title: what changed (72 chars max)
- Body: why it changed
- Example: "Add Patient Hub page\n\nImplement plain-language..."

### Tip 4: Test Before Pushing
- Run `git status` to see what's being added
- Run `git ls-files` to verify file list
- Check `.gitignore` does its job
