## ✅ Pre-Push Verification

Before pushing, verify:
```bash
# 1. .gitignore exists?
test -f .gitignore && echo "✅ OK" || echo "❌ Missing"

# 2. Git initialized?
git status 2>/dev/null | grep "fatal" && echo "❌ Not initialized" || echo "✅ OK"

# 3. Files ready? (~42)
git add . && git ls-files | wc -l

# 4. Large files excluded?
git ls-files | grep -E "gtex|gwas|expression" | wc -l
# Should output: 0 (nothing)
```
